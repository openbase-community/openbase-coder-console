# Openbase Coder Console

React web console for Openbase Coder.

This package is the browser entry point for the Openbase Coder UI. It mounts the
shared `@openbase/coder-react` application, wires in plugin registry data, and
serves the app with Vite during local development.

Most reusable interface code lives in the sibling
[`coder-react`](https://github.com/openbase-community/openbase-coder-react)
package. The local backend is provided by the
[`openbase-coder`](https://github.com/openbase-community/openbase) CLI.

## Repository Layout

```text
src/main.tsx                  Vite/React entry point
src/pluginLoader.ts          Loads generated plugin registry modules
src/generated/pluginRegistry.ts
                              Generated plugin page/project-view registry
src/*.test.ts                Focused Vitest coverage for console helpers
vite.config.ts               Vite aliases for workspace packages
```

## Development

This repo is normally used inside the `openbase-coder-workspace` multi
workspace, next to these sibling packages:

```text
../coder-react
../multi-react
../boilersync-react
```

Install workspace dependencies from the workspace root:

```bash
pnpm install
```

Start the console dev server:

```bash
pnpm --filter vite_react_shadcn_ts dev
```

The Vite server listens on port `8080` by default. The console expects the
Openbase Coder CLI backend to be running separately.

## Scripts

```bash
pnpm --filter vite_react_shadcn_ts build
pnpm --filter vite_react_shadcn_ts build:dev
pnpm --filter vite_react_shadcn_ts preview
pnpm --filter vite_react_shadcn_ts lint
pnpm --filter vite_react_shadcn_ts test
pnpm --filter vite_react_shadcn_ts test:e2e
```

Generate API types from a running backend:

```bash
pnpm --filter vite_react_shadcn_ts generate-types
```

## Plugins

`src/generated/pluginRegistry.ts` is generated by Openbase Coder plugin sync. It
exports console pages and project views that are passed into the shared React
app through `PluginRegistryProvider`.

Do not hand-maintain plugin entries in that file unless you are intentionally
debugging plugin loading.

## Environment

Tracked environment files only contain public Vite configuration. Do not commit
private keys, service tokens, cookies, or local backend credentials.

Supported public settings include:

```text
VITE_GA_TRACKING_ID
VITE_USE_CDN
```

`VITE_USE_CDN=true` changes the production asset base to the configured
Openbase CDN path in `vite.config.ts`.
